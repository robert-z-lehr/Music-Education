# Lesson Media

Use this folder for teacher-created audio, video, notation images, and other media used by the student-facing lessons.

## Suggested structure

```text
assets/
  lesson-01/
    melody-normal.mp3
    melody-slow.mp3
    phrase-01-loop.mp4
    keyboard-overhead.mp4
  lesson-02/
    rhythm-example-01.mp3
```

## Good clip design

Keep clips short and purpose-specific.

For a difficult phrase, consider providing:

1. normal-speed performance
2. slow performance
3. isolated 2–5 second loop
4. overhead keyboard view
5. optional notation image created by you

## Naming convention

Prefer descriptive lowercase names with hyphens.

Examples:

- `theme-a-normal.mp3`
- `theme-a-slow.mp3`
- `measure-03-loop.mp4`
- `left-hand-pattern.mp4`

## Copyright

Only publish media you have the right to distribute. For copyrighted commercial method books or recordings, link to lawful sources or assign the student's own copy rather than uploading scans, ripped audio, photographed pages, or answer keys.
